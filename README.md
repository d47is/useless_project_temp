# RageSlayer 🎯

## Basic Details
### name : Davis Jolly Mathew
### college_name : sjcet,palai


### Project Description
RageSlayer is a browser extension overlay that injects a chaotic AI assistant into any frustrating webpage. Talk to your AI Homie, unlock a heavy arsenal (pistols, flamethrowers, and missiles), and visually wreck the site in real time.

### The Problem (that doesn't exist)
Websites take too long to load, show annoying popups, or look ugly, but traditional inspect-element editing lacks satisfying audio-visual destruction and tactical explosives.

### The Solution (that nobody asked for)
An AI companion that listens to your grievances, validates your rage, and equips you with cursor-tracked weaponry—allowing you to crack screens, blast fire streams, and detonate 5x missile strikes directly on the browser page.

## Technical Details
### Technologies/Components Used
For Software:
- **Languages:** JavaScript (ES6+), HTML5, CSS3
- **Frameworks:** Web Extensions API (Chrome / Edge Manifest v3)
- **Libraries:** Web Audio API (Procedural sound synthesis), Canvas API (Flame particle engine)
- **Tools:** VS Code, Groq API (`openai/gpt-oss-20b`)

# Installation
1. Clone or download this repository to your local machine.
2. Open Google Chrome (or any Chromium browser) and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the project folder containing `manifest.json`.

# Run
1. Open any website in your browser.
2. Click the **RageSlayer** extension icon or refresh the active tab.
3. Chat with the AI Homie to unlock your arsenal.
4. Select **🔫 Pistol**, **🔥 Flamethrower**, or **🚀 Missile** to start destroying the UI!
